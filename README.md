# Личный сайт

Это исходники статического сайта. Редактировать руками нужно файлы в корне репозитория, а не `docs/`.

## Где что лежит

- `index.md` — главная страница, она же раздел «Пишу».
- `products.md` — раздел «Делаю».
- `work.md` — черновик профессионального раздела, сейчас не публикуется.
- `blog.md` — редирект со старого `/blog/` на главную.
- `404.md` — страница ошибки.
- `*.md` в корне — отдельные материалы и артефакты.
- `_includes/base.njk` — общий шаблон с шапкой, меню и футером.
- `_includes/entry-list.njk` — общий список материалов.
- `style.css` — стили сайта.
- `_data/site.json` — имя, описание и реальные контакты.
- `_templates/` — шаблоны для новых материалов, не публикуются на сайте.
- `_drafts/` — черновики и незавершенные материалы, не публикуются на сайте.
- `backlog.md` — внутренний список задач, не публикуется.
- `soon.md` — публичный сад идей.
- `docs/` — собранный сайт для публикации, руками не редактировать.

## Как добавить артефакт

1. Скопировать `_templates/artifact.md` в корень репозитория.
2. Переименовать файл латиницей, например `stickers-cinema-club.md`.
3. Заполнить `title`, `description` и текст страницы.
4. Поставить `section: product`, если это должно появиться в «Делаю» и на главной.
5. Запустить `npx @11ty/eleventy`.

Если материал еще сырой, положить его в `_drafts/`. Оттуда он не попадет в `docs/`.

## Как добавить пост

1. Скопировать `_templates/new-note.md` в корень репозитория.
2. Переименовать файл латиницей.
3. Заполнить `title`, `description`, `date` и текст.
4. Оставить `section: blog`, чтобы пост появился на главной.

## Сборка

```sh
npx @11ty/eleventy
```
