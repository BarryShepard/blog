Устанавливаем окружение

  1. Ставим homebrew /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Устанавливаем консольный стим. Обычно его используют для удаленного обновления игр на серверах. Нам нужен функуионал стим brew install steamcmd
